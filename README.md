# ChatApp

A simple real-time chat application built in Swift using WebSockets.

## ✨ Features

- One-to-one chat interface
- Message sending via WebSocket
- Queued and failed message handling
- Unread message preview in chat list
- Message status updates (queued, sent, failed)
- Automatically clears chat when app is closed (killed state)


## 🛠 Tech Stack

- **Language:** Swift
- **Networking:** URLSession, WebSocket
- **UI:** UIKit (UITableView, UITextField, Custom Cells)
